## 🌐 Sobre o Projeto

Este projeto é uma **apresentação interativa** pensada para:

- ✅ **Exibir habilidades técnicas**  
- ✅ **Demonstrar boas práticas em Frontend**  
- ✅ **Servir como material acadêmico e portfólio público**  

💡 **Diferenciais:**  
- Layout moderno e responsivo  
- Componentes reutilizáveis em React  
- Uso elegante de ícones minimalistas (Lucide Icons)  
- Funciona direto no navegador, sem build complexa
